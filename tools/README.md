# Artes @espanhasemsegredo

`python3 tools/art.py [noticia|intercambio|cafe]` gera os PNGs (saida em `ART_OUT`, padrão `saida/`) com Playwright.
Padrão da marca: Lora + Inter; verde #0F3D3A/#1E5550, dourado #C9A24A, terracota #B8573A, marfim #F5F1E8; logo `marca/logo-espanha-sem-segredo.png` no rodapé e no último slide.
Regras: arte sempre original no padrão da marca, nunca o gerador automático do Canva, nunca reaproveitar arte já usada.
